# Financeiro Eurosport: instaladores

Este repositório é **público** e guarda **somente os instaladores** do app:

- `.exe` para Windows
- `.apk` para Android
- o arquivo de versão que o app consulta para se atualizar sozinho

**Não há código-fonte nem dados aqui.** O código fica num repositório privado, e os dados ficam na nuvem da empresa, protegidos por login. Os instaladores são gerados automaticamente a cada versão e publicados na aba **Releases**.

## Como instalar

- **Windows:** baixe o `.exe` da versão mais recente em Releases e abra. Depois disso, o app avisa sozinho quando tem versão nova.
- **Android:** baixe o `.apk` pelo celular e toque em Instalar. Na primeira vez, permita instalar apps dessa origem.
